# Roadmap

Near-term:

- edge diff visualization
- diff list view (filter + click-to-center)
- history timeline diff (L/R)
- replay animation (highlight target, step)
- golden replay hashes in CI

Medium-term:

- three-way merge semantics + visualizer
- schema evolution rules + compatibility checks
- larger examples and performance scaling

Long-term:

- multi-language validators (Rust/Haskell)
- richer replay semantics (state materialization)
- WebGL renderer

Principle: keep the kernel minimal; grow features around it.
